class backends.db.SessionStore

classmethod get_model_class()  
Override this method to return a custom session model if you need one. 
  
create_model_instance(data)  
Returns a new instance of the session model object, which represents the current session state. Overriding this method provides the ability to modify session model data before it’s saved to database.
