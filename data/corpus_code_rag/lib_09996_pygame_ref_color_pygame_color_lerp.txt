# pygame.ref.color#pygame.Color.lerp

lerp() 
 returns a linear interpolation to the given Color. lerp(Color, float) -> Color  Returns a Color which is a linear interpolation between self and the given Color in RGBA space. The second parameter determines how far between self and other the result is going to be. It must be a value between 0 and 1 where 0 means self and 1 means other will be returned.  New in pygame 2.0.1.
