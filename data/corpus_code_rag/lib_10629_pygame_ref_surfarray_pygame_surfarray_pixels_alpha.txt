# pygame.ref.surfarray#pygame.surfarray.pixels_alpha

pygame.surfarray.pixels_alpha() 
 Reference pixel alphas into a 2d array pixels_alpha(Surface) -> array  Create a new 2D array that directly references the alpha values (degree of transparency) in a Surface. Any changes to the array will affect the pixels in the Surface. This is a fast operation since no data is copied. This can only work on 32-bit Surfaces with a per-pixel alpha value. The Surface this array references will remain locked for the lifetime of the array.
