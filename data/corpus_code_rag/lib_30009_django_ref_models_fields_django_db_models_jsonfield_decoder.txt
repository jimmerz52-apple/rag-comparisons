# django.ref.models.fields#django.db.models.JSONField.decoder

JSONField.decoder  
An optional json.JSONDecoder subclass to deserialize the value retrieved from the database. The value will be in the format chosen by the custom encoder (most often a string). Your deserialization may need to account for the fact that you can’t be certain of the input type. For example, you run the risk of returning a datetime that was actually a string that just happened to be in the same format chosen for datetimes. Defaults to json.JSONDecoder.
