# werkzeug.wsgi.index#werkzeug.wsgi.get_content_length

werkzeug.wsgi.get_content_length(environ)  
Returns the content length from the WSGI environment as integer. If it’s not available or chunked transfer encoding is used, None is returned.  Changelog New in version 0.9.   Parameters 
environ (WSGIEnvironment) – the WSGI environ to fetch the content length from.  Return type 
Optional[int]
