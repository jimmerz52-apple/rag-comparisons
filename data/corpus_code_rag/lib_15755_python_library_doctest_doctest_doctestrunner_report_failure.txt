# python.library.doctest#doctest.DocTestRunner.report_failure

report_failure(out, test, example, got)  
Report that the given example failed. This method is provided to allow subclasses of DocTestRunner to customize their output; it should not be called directly. example is the example about to be processed. got is the actual output from the example. test is the test containing example. out is the output function that was passed to DocTestRunner.run().
