# torch.named_tensor#torch.Tensor.names

names  
Stores names for each of this tensor’s dimensions. names[idx] corresponds to the name of tensor dimension idx. Names are either a string if the dimension is named or None if the dimension is unnamed. Dimension names may contain characters or underscore. Furthermore, a dimension name must be a valid Python variable name (i.e., does not start with underscore). Tensors may not have two named dimensions with the same name.  Warning The named tensor API is experimental and subject to change.
