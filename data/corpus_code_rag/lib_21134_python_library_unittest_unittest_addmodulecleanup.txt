# python.library.unittest#unittest.addModuleCleanup

unittest.addModuleCleanup(function, /, *args, **kwargs)  
Add a function to be called after tearDownModule() to cleanup resources used during the test class. Functions will be called in reverse order to the order they are added (LIFO). They are called with any arguments and keyword arguments passed into addModuleCleanup() when they are added. If setUpModule() fails, meaning that tearDownModule() is not called, then any cleanup functions added will still be called.  New in version 3.8.
