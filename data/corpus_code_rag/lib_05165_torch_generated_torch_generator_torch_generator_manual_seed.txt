# torch.generated.torch.generator#torch.Generator.manual_seed

manual_seed(seed) → Generator  
Sets the seed for generating random numbers. Returns a torch.Generator object. It is recommended to set a large seed, i.e. a number that has a good balance of 0 and 1 bits. Avoid having many 0 bits in the seed.  Parameters 
seed (int) – The desired seed. Value must be within the inclusive range [-0x8000_0000_0000_0000, 0xffff_ffff_ffff_ffff]. Otherwise, a RuntimeError is raised. Negative inputs are remapped to positive values with the formula 0xffff_ffff_ffff_ffff + seed.  Returns 
An torch.Generator object.  Return type 
Generator   Example: >>> g_cpu = torch.Generator()
>>> g_cpu.manual_seed(2147483647)
