# tensorflow.raw_ops.softsign

tf.raw_ops.Softsign Computes softsign: features / (abs(features) + 1).  View aliases  Compat aliases for migration 
See Migration guide for more details. tf.compat.v1.raw_ops.Softsign  
tf.raw_ops.Softsign(
    features, name=None
)

 


 Args
  features   A Tensor. Must be one of the following types: half, bfloat16, float32, float64.  
  name   A name for the operation (optional).   
 


 Returns   A Tensor. Has the same type as features.
