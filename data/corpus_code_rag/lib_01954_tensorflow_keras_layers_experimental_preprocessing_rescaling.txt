tf.keras.layers.experimental.preprocessing.Rescaling(
    scale, offset=0.0, name=None, **kwargs
)
 For instance:  To rescale an input in the [0, 255] range to be in the [0, 1] range, you would pass scale=1./255. To rescale an input in the [0, 255] range to be in the [-1, 1] range, you would pass scale=1./127.5, offset=-1.  The rescaling is applied both during training and inference. Input shape: Arbitrary. Output shape: Same as input.
 


 Arguments
  scale   Float, the scale to apply to the inputs.  
  offset   Float, the offset to apply to the inputs.
