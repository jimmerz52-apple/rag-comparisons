# python.library.types#types.ModuleType.__package__

__package__  
Which package a module belongs to. If the module is top-level (i.e. not a part of any specific package) then the attribute should be set to '', else it should be set to the name of the package (which can be __name__ if the module is a package itself). Defaults to None. This attribute is to match importlib.machinery.ModuleSpec.parent as stored in the attr:__spec__ object.  Note A future version of Python may stop setting this attribute by default. To guard against this potential change, preferrably read from the __spec__ attribute instead or use getattr(module, "__package__", None) if you explicitly need to use this attribute.   Changed in version 3.4: Defaults to None. Previously the attribute was optional.
