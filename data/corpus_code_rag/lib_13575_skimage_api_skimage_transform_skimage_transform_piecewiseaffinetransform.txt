class skimage.transform.PiecewiseAffineTransform [source]
 
Bases: skimage.transform._geometric.GeometricTransform 2D piecewise affine transformation. Control points are used to define the mapping. The transform is based on a Delaunay triangulation of the points to form a mesh. Each triangle is used to find a local affine transform.  Attributes 
 
affineslist of AffineTransform objects 

Affine transformations for each triangle in the mesh.

Inverse affine transformations for each triangle in the mesh.
