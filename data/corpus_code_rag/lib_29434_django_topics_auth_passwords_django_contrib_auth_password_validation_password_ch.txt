# django.topics.auth.passwords#django.contrib.auth.password_validation.password_changed

password_changed(password, user=None, password_validators=None)  
Informs all validators that the password has been changed. This can be used by validators such as one that prevents password reuse. This should be called once the password has been successfully changed. For subclasses of AbstractBaseUser, the password field will be marked as “dirty” when calling set_password() which triggers a call to password_changed() after the user is saved.
