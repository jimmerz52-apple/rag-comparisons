# tensorflow.math.is_finite

tf.math.is_finite Returns which elements of x are finite.  View aliases  Compat aliases for migration 
See Migration guide for more details. tf.compat.v1.debugging.is_finite, tf.compat.v1.is_finite, tf.compat.v1.math.is_finite  
tf.math.is_finite(
    x, name=None
)
 Example: x = tf.constant([5.0, 4.8, 6.8, np.inf, np.nan])
tf.math.is_finite(x) ==> [True, True, True, False, False]

 


 Args
  x   A Tensor. Must be one of the following types: bfloat16, half, float32, float64.  
  name   A name for the operation (optional).   
 


 Returns   A Tensor of type bool.  
 Numpy Compatibility Equivalent to np.isfinite
