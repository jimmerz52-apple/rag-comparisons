# django.ref.contrib.postgres.indexes#django.contrib.postgres.indexes.HashIndex

class HashIndex(*expressions, fillfactor=None, **options)  
Creates a hash index. Provide an integer value from 10 to 100 to the fillfactor parameter to tune how packed the index pages will be. PostgreSQL’s default is 90.  Use this index only on PostgreSQL 10 and later Hash indexes have been available in PostgreSQL for a long time, but they suffer from a number of data integrity issues in older versions.   Changed in Django 3.2: Positional argument *expressions was added in order to support functional indexes.
