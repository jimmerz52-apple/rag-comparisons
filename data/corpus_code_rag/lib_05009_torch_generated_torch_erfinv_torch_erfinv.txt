torch.erfinv(input, *, out=None) → Tensor  
Computes the inverse error function of each element of input. The inverse error function is defined in the range (−1,1)(-1, 1)  as:  erfinv(erf(x))=x\mathrm{erfinv}(\mathrm{erf}(x)) = x  
 Parameters 
input (Tensor) – the input tensor.  Keyword Arguments 
out (Tensor, optional) – the output tensor.   Example: >>> torch.erfinv(torch.tensor([0, 0.5, -1.]))
tensor([ 0.0000,  0.4769,    -inf])
