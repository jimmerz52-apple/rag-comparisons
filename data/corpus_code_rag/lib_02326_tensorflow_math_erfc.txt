# tensorflow.math.erfc

tf.math.erfc Computes the complementary error function of x element-wise.  View aliases  Compat aliases for migration 
See Migration guide for more details. tf.compat.v1.erfc, tf.compat.v1.math.erfc  
tf.math.erfc(
    x, name=None
)

 


 Args
  x   A Tensor. Must be one of the following types: bfloat16, half, float32, float64.  
  name   A name for the operation (optional).   
 


 Returns   A Tensor. Has the same type as x.
