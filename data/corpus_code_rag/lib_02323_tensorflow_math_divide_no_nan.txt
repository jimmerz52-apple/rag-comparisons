# tensorflow.math.divide_no_nan

tf.math.divide_no_nan     View source on GitHub    Computes a safe divide which returns 0 if the y is zero.  View aliases  Compat aliases for migration 
See Migration guide for more details. tf.compat.v1.div_no_nan, tf.compat.v1.math.divide_no_nan  
tf.math.divide_no_nan(
    x, y, name=None
)

 


 Args
  x   A Tensor. Must be one of the following types: float32, float64.  
  y   A Tensor whose dtype is compatible with x.  
  name   A name for the operation (optional).   
 


 Returns   The element-wise value of the x divided by y.
