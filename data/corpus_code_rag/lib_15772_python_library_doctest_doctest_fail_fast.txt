# python.library.doctest#doctest.FAIL_FAST

doctest.FAIL_FAST  
When specified, exit after the first failing example and don’t attempt to run the remaining examples. Thus, the number of failures reported will be at most 1. This flag may be useful during debugging, since examples after the first failure won’t even produce debugging output. The doctest command line accepts the option -f as a shorthand for -o
FAIL_FAST.  New in version 3.4.
