classmatplotlib.transforms.BboxBase(shorthand_name=None)[source]
 
Bases: matplotlib.transforms.TransformNode The base class of all bounding boxes. This class is immutable; Bbox is a mutable subclass. The canonical representation is as two points, with no restrictions on their ordering. Convenience properties are provided to get the left, bottom, right and top edges and width and height, but these are not stored explicitly.  Parameters
