# python.library.ast#ast.AugAssign

class ast.AugAssign(target, op, value)  
Augmented assignment, such as a += 1. In the following example, target is a Name node for x (with the Store context), op is Add, and value is a Constant with value for 1. The target attribute connot be of class Tuple or List, unlike the targets of Assign. >>> print(ast.dump(ast.parse('x += 2'), indent=4))
Module(
    body=[
        AugAssign(
            target=Name(id='x', ctx=Store()),
            op=Add(),
            value=Constant(value=2))],
    type_ignores=[])
