# flask.api.index#flask.Flask.use_x_sendfile

use_x_sendfile  
Enable this if you want to use the X-Sendfile feature. Keep in mind that the server has to support this. This only affects files sent with the send_file() method.  Changelog New in version 0.2.  This attribute can also be configured from the config with the USE_X_SENDFILE configuration key. Defaults to False.
