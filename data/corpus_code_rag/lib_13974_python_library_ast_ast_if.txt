# python.library.ast#ast.If

class ast.If(test, body, orelse)  
An if statement. test holds a single node, such as a Compare node. body and orelse each hold a list of nodes. elif clauses don’t have a special representation in the AST, but rather appear as extra If nodes within the orelse section of the previous one. >>> print(ast.dump(ast.parse("""
... if x:
...    ...
... elif y:
...    ...
... else:
...    ...
... """), indent=4))
Module(
    body=[
        If(
            test=Name(id='x', ctx=Load()),
            body=[
                Expr(
                    value=Constant(value=Ellipsis))],
            orelse=[
                If(
                    test=Name(id='y', ctx=Load()),
                    body=[
                        Expr(
                            value=Constant(value=Ellipsis))],
                    orelse=[
                        Expr(
                            value=Constant(value=Ellipsis))])])],
    type_ignores=[])
