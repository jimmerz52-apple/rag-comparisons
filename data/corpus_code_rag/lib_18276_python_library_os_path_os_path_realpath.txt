os.path.realpath(path)  
Return the canonical path of the specified filename, eliminating any symbolic links encountered in the path (if they are supported by the operating system).  Note When symbolic link cycles occur, the returned path will be one member of the cycle, but no guarantee is made about which member that will be.   Changed in version 3.6: Accepts a path-like object.   Changed in version 3.8: Symbolic links and junctions are now resolved on Windows.
