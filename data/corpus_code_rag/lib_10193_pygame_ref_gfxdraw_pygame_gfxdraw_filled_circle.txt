# pygame.ref.gfxdraw#pygame.gfxdraw.filled_circle

pygame.gfxdraw.filled_circle() 
 draw a filled circle filled_circle(surface, x, y, r, color) -> None  Draws a filled circle on the given surface. For an unfilled circle use circle().     
Parameters:

 
surface (Surface) -- surface to draw on 
x (int) -- x coordinate of the center of the circle 
y (int) -- y coordinate of the center of the circle 
r (int) -- radius of the circle 
color (Color or tuple(int, int, int, [int])) -- color to draw with, the alpha value is optional if using a tuple (RGB[A])
    
Returns:

None   
Return type:

NoneType
