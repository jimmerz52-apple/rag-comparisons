# pygame.ref.color#pygame.Color.set_length

set_length() 
 Set the number of elements in the Color to 1,2,3, or 4. set_length(len) -> None  The default Color length is 4. Colors can have lengths 1,2,3 or 4. This is useful if you want to unpack to r,g,b and not r,g,b,a. If you want to get the length of a Color do len(acolor).  New in pygame 1.9.0.
