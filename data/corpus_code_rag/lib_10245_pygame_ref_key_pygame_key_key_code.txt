# pygame.ref.key#pygame.key.key_code

pygame.key.key_code() 
 get the key identifier from a key name key_code(name=string) -> int  Get the key identifier code from the descriptive name of the key. This returns an integer matching one of the K_* keycodes. For example: >>> pygame.key.key_code("return") == pygame.K_RETURN
True
>>> pygame.key.key_code("0") == pygame.K_0
True
>>> pygame.key.key_code("space") == pygame.K_SPACE
True     
Raises:

 
ValueError -- if the key name is not known. 
NotImplementedError -- if used with SDL 1.       New in pygame 2.0.0.
