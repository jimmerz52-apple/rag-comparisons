# tensorflow.raw_ops.sqrt

tf.raw_ops.Sqrt   Computes square root of x element-wise.  View aliases  Compat aliases for migration 
See Migration guide for more details. tf.compat.v1.raw_ops.Sqrt  
tf.raw_ops.Sqrt(
    x, name=None
)
 I.e., \(y = \sqrt{x} = x^{1/2}\).
 


 Args
  x   A Tensor. Must be one of the following types: bfloat16, half, float32, float64, complex64, complex128.  
  name   A name for the operation (optional).   
 


 Returns   A Tensor. Has the same type as x.
