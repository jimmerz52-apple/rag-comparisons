# django.ref.contrib.messages#django.contrib.messages.storage.cookie.CookieStorage

class storage.cookie.CookieStorage  
This class stores the message data in a cookie (signed with a secret hash to prevent manipulation) to persist notifications across requests. Old messages are dropped if the cookie data size would exceed 2048 bytes.  Changed in Django 3.2: Messages format was changed to the RFC 6265 compliant format.
