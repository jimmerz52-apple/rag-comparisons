CursorWrapper.callproc(procname, params=None, kparams=None)  
Calls a database stored procedure with the given name. A sequence (params) or dictionary (kparams) of input parameters may be provided. Most databases don’t support kparams. Of Django’s built-in backends, only Oracle supports it. For example, given this stored procedure in an Oracle database: CREATE PROCEDURE "TEST_PROCEDURE"(v_i INTEGER, v_text NVARCHAR2(10)) AS
    p_i INTEGER;
    p_text NVARCHAR2(10);
BEGIN
    p_i := v_i;
    p_text := v_text;
    ...
END;
 This will call it: with connection.cursor() as cursor:
    cursor.callproc('test_procedure', [1, 'test'])
