# python.library.gettext#gettext.bind_textdomain_codeset

gettext.bind_textdomain_codeset(domain, codeset=None)  
Bind the domain to codeset, changing the encoding of byte strings returned by the lgettext(), ldgettext(), lngettext() and ldngettext() functions. If codeset is omitted, then the current binding is returned.  Deprecated since version 3.8, will be removed in version 3.10.
