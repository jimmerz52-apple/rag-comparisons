# pygame.ref.surfarray#pygame.surfarray.pixels_blue

pygame.surfarray.pixels_blue() 
 Reference pixel blue into a 2d array. pixels_blue (Surface) -> array  Create a new 2D array that directly references the blue values in a Surface. Any changes to the array will affect the pixels in the Surface. This is a fast operation since no data is copied. This can only work on 24-bit or 32-bit Surfaces. The Surface this array references will remain locked for the lifetime of the array.
