# pygame.ref.math#pygame.math.Vector3.rotate_z_rad

rotate_z_rad() 
 rotates a vector around the z-axis by the angle in radians. rotate_z_rad(angle) -> Vector3  Returns a vector which has the same length as self but is rotated counterclockwise around the z-axis by the given angle in radians.  New in pygame 2.0.0.
