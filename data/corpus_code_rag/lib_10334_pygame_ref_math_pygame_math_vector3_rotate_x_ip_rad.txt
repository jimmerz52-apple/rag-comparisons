# pygame.ref.math#pygame.math.Vector3.rotate_x_ip_rad

rotate_x_ip_rad() 
 rotates the vector around the x-axis by the angle in radians in place. rotate_x_ip_rad(angle) -> None  Rotates the vector counterclockwise around the x-axis by the given angle in radians. The length of the vector is not changed.  New in pygame 2.0.0.
