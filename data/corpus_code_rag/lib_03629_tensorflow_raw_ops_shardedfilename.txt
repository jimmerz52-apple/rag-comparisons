# tensorflow.raw_ops.shardedfilename

tf.raw_ops.ShardedFilename Generate a sharded filename. The filename is printf formatted as  View aliases  Compat aliases for migration 
See Migration guide for more details. tf.compat.v1.raw_ops.ShardedFilename  
tf.raw_ops.ShardedFilename(
    basename, shard, num_shards, name=None
)
 %s-%05d-of-%05d, basename, shard, num_shards.
 


 Args
  basename   A Tensor of type string.  
  shard   A Tensor of type int32.  
  num_shards   A Tensor of type int32.  
  name   A name for the operation (optional).   
 


 Returns   A Tensor of type string.
