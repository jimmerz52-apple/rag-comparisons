# django.ref.contrib.auth#django.contrib.auth.backends.ModelBackend.with_perm

with_perm(perm, is_active=True, include_superusers=True, obj=None)  
Returns all active users who have the permission perm either in the form of "<app label>.<permission codename>" or a Permission instance. Returns an empty queryset if no users who have the perm found. If is_active is True (default), returns only active users, or if False, returns only inactive users. Use None to return all users irrespective of active state. If include_superusers is True (default), the result will include superusers.
