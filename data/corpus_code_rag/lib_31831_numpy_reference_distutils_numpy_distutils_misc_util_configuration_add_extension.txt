# numpy.reference.distutils#numpy.distutils.misc_util.Configuration.add_extension

add_extension(name, sources, **kw)[source]
 
Add extension to configuration. Create and add an Extension instance to the ext_modules list. This method also takes the following optional keyword arguments that are passed on to the Extension constructor.  Parameters 
 
namestr


name of the extension  
sourcesseq


list of the sources. The list of sources may contain functions (called source generators) which must take an extension instance and a build directory as inputs and return a source file or list of source files or None. If None is returned then no sources are generated. If the Extension instance has no sources after processing all source generators, then no extension module is built.  include_dirs :
