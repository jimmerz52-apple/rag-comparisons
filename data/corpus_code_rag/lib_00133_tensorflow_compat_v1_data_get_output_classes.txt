# tensorflow.compat.v1.data.get_output_classes

tf.compat.v1.data.get_output_classes Returns the output classes for elements of the input dataset / iterator. 
tf.compat.v1.data.get_output_classes(
    dataset_or_iterator
)

 


 Args
  dataset_or_iterator   A tf.data.Dataset or tf.data.Iterator.   
 


 Returns   A nested structure of Python type objects matching the structure of the dataset / iterator elements and specifying the class of the individual components.
