# tensorflow.math.erfinv

tf.math.erfinv Compute inverse error function.  View aliases  Compat aliases for migration 
See Migration guide for more details. tf.compat.v1.math.erfinv  
tf.math.erfinv(
    x, name=None
)
 Given x, compute the inverse error function of x. This function is the inverse of tf.math.erf.
 


 Args
  x   Tensor with type float or double.  
  name   A name for the operation (optional).   
 


 Returns   Inverse error function of x.
