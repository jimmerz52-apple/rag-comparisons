# tensorflow.math.erfcinv

tf.math.erfcinv Computes the inverse of complementary error function.  View aliases  Compat aliases for migration 
See Migration guide for more details. tf.compat.v1.math.erfcinv  
tf.math.erfcinv(
    x, name=None
)
 Given x, compute the inverse complementary error function of x. This function is the inverse of tf.math.erfc, and is defined on [0, 2].
