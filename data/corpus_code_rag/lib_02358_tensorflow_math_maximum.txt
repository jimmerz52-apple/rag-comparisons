# tensorflow.math.maximum

tf.math.maximum Returns the max of x and y (i.e. x > y ? x : y) element-wise.  View aliases  Main aliases 
tf.maximum Compat aliases for migration See Migration guide for more details. tf.compat.v1.math.maximum, tf.compat.v1.maximum  
tf.math.maximum(
    x, y, name=None
)
 Example: 
x = tf.constant([0., 0., 0., 0.])
y = tf.constant([-2., 0., 2., 5.])
tf.math.maximum(x, y)
<tf.Tensor: shape=(4,), dtype=float32, numpy=array([0., 0., 2., 5.], dtype=float32)>

 


 Args
  x   A Tensor. Must be one of the following types: bfloat16, half, float32, float64, uint8, int16, int32, int64.  
  y   A Tensor. Must have the same type as x.  
  name   A name for the operation (optional).   
 


 Returns   A Tensor. Has the same type as x.
