# tensorflow.math.not_equal

tf.math.not_equal     View source on GitHub    Returns the truth value of (x != y) element-wise.  View aliases  Main aliases 
tf.not_equal Compat aliases for migration See Migration guide for more details. tf.compat.v1.math.not_equal, tf.compat.v1.not_equal  
tf.math.not_equal(
    x, y, name=None
)
 Performs a broadcast with the arguments and then an element-wise inequality comparison, returning a Tensor of boolean values. For example: 
x = tf.constant([2, 4])
y = tf.constant(2)
tf.math.not_equal(x, y)
<tf.Tensor: shape=(2,), dtype=bool, numpy=array([False,  True])>
 
x = tf.constant([2, 4])
y = tf.constant([2, 4])
tf.math.not_equal(x, y)
<tf.Tensor: shape=(2,), dtype=bool, numpy=array([False,  False])>

 


 Args
  x   A tf.Tensor or tf.sparse.SparseTensor or tf.IndexedSlices.  
  y   A tf.Tensor or tf.sparse.SparseTensor or tf.IndexedSlices.  
  name   A name for the operation (optional).   
 


 Returns   A tf.Tensor of type bool with the same size as that of x or y.  

 


 Raises   tf.errors.InvalidArgumentError: If shapes of arguments are incompatible
