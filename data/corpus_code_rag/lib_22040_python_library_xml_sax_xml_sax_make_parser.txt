# python.library.xml.sax#xml.sax.make_parser

xml.sax.make_parser(parser_list=[])  
Create and return a SAX XMLReader object. The first parser found will be used. If parser_list is provided, it must be an iterable of strings which name modules that have a function named create_parser(). Modules listed in parser_list will be used before modules in the default list of parsers.  Changed in version 3.8: The parser_list argument can be any iterable, not just a list.
