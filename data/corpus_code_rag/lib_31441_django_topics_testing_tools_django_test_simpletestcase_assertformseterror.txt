# django.topics.testing.tools#django.test.SimpleTestCase.assertFormsetError

SimpleTestCase.assertFormsetError(response, formset, form_index, field, errors, msg_prefix='')  
Asserts that the formset raises the provided list of errors when rendered. response must be a response instance returned by the test client. formset is the name the Formset instance was given in the template context of the response. form_index is the number of the form within the Formset. If form_index has a value of None, non-form errors (errors you can access via formset.non_form_errors()) will be checked. field is the name of the field on the form to check. If field has a value of None, non-field errors (errors you can access via form.non_field_errors()) will be checked. errors is an error string, or a list of error strings, that are expected as a result of form validation.
