# werkzeug.routing.index#werkzeug.routing.Map.is_endpoint_expecting

is_endpoint_expecting(endpoint, *arguments)  
Iterate over all rules and check if the endpoint expects the arguments provided. This is for example useful if you have some URLs that expect a language code and others that do not and you want to wrap the builder a bit so that the current language code is automatically added if not provided but endpoints expect it.  Parameters 
 
endpoint (str) – the endpoint to check. 
arguments (str) – this function accepts one or more arguments as positional arguments. Each one of them is checked.   Return type 
bool
