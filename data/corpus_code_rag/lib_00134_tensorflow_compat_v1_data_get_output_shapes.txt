# tensorflow.compat.v1.data.get_output_shapes

tf.compat.v1.data.get_output_shapes Returns the output shapes for elements of the input dataset / iterator. 
tf.compat.v1.data.get_output_shapes(
    dataset_or_iterator
)

 


 Args
  dataset_or_iterator   A tf.data.Dataset or tf.data.Iterator.   
 


 Returns   A nested structure of tf.TensorShape objects matching the structure of the dataset / iterator elements and specifying the shape of the individual components.
