# python.library.ssl#ssl.SSLContext.num_tickets

SSLContext.num_tickets  
Control the number of TLS 1.3 session tickets of a TLS_PROTOCOL_SERVER context. The setting has no impact on TLS 1.0 to 1.2 connections.  Note This attribute is not available unless the ssl module is compiled with OpenSSL 1.1.1 or newer.   New in version 3.8.
