# torch.fx#torch.fx.Interpreter.run

run(*args, initial_env=None) [source]
 
Run module via interpretation and return the result.  Parameters 
 
*args – The arguments to the Module to run, in positional order 
initial_env (Optional[Dict[Node, Any]]) – An optional starting environment for execution. This is a dict mapping Node to any value. This can be used, for example, to pre-populate results for certain Nodes so as to do only partial evaluation within the interpreter.   Returns 
The value returned from executing the Module  Return type 
Any
