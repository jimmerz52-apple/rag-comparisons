# tensorflow.math.is_inf

tf.math.is_inf Returns which elements of x are Inf.  View aliases  Compat aliases for migration 
See Migration guide for more details. tf.compat.v1.debugging.is_inf, tf.compat.v1.is_inf, tf.compat.v1.math.is_inf  
tf.math.is_inf(
    x, name=None
)
 Example: x = tf.constant([5.0, np.inf, 6.8, np.inf])
tf.math.is_inf(x) ==> [False, True, False, True]

 


 Args
  x   A Tensor. Must be one of the following types: bfloat16, half, float32, float64.  
  name   A name for the operation (optional).   
 


 Returns   A Tensor of type bool.  
 Numpy Compatibility Equivalent to np.isinf
