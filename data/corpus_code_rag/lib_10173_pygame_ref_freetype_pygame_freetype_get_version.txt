# pygame.ref.freetype#pygame.freetype.get_version

pygame.freetype.get_version() 
 Return the FreeType version get_version() -> (int, int, int)  Returns the version of the FreeType library in use by this module. Note that the freetype module depends on the FreeType 2 library. It will not compile with the original FreeType 1.0. Hence, the first element of the tuple will always be "2".
