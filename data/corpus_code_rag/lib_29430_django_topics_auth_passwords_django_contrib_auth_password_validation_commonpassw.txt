# django.topics.auth.passwords#django.contrib.auth.password_validation.CommonPasswordValidator

class CommonPasswordValidator(password_list_path=DEFAULT_PASSWORD_LIST_PATH)  
Validates whether the password is not a common password. This converts the password to lowercase (to do a case-insensitive comparison) and checks it against a list of 20,000 common password created by Royce Williams. The password_list_path can be set to the path of a custom file of common passwords. This file should contain one lowercase password per line and may be plain text or gzipped.
