# python.library.os#os.unlink

os.unlink(path, *, dir_fd=None)  
Remove (delete) the file path. This function is semantically identical to remove(); the unlink name is its traditional Unix name. Please see the documentation for remove() for further information. Raises an auditing event os.remove with arguments path, dir_fd.  New in version 3.3: The dir_fd parameter.   Changed in version 3.6: Accepts a path-like object.
